# Wellness Program — Clean Test Build

This build starts blank and is designed for end-to-end testing with dummy data.

Included:
- separate Member and Coach test entry points
- blank member onboarding
- supplement list captured during onboarding
- coach supplement follow-up view
- water starts at 0
- B4B fixed at 5,000 before breakfast
- 42-day cycles
- protein days on Days 1–3 and every Monday thereafter
- cycle/day tracking
- coach dashboard alerts
- notes to coach
- coach-only client view structure

Important: this is still a public prototype using local browser storage. It does not yet have secure authentication, cloud sync or production permissions. Use test data only.
